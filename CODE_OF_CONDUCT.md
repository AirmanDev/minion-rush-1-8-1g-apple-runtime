# Code of Conduct

This project expects calm, factual, and inclusive technical collaboration.

## Expected behavior

- Address the problem and evidence, not the person.
- Make criticism specific, verifiable, and actionable.
- Respect contributors' time with minimal reproductions, exact test results,
  and focused changes.
- Respect licensing, privacy, and copyright boundaries.

Harassment, personal attacks, threats, hate speech, deliberate disruption, and
publishing personal information are unacceptable.

## Enforcement

Maintainers may edit or remove content that violates these rules and may
temporarily or permanently restrict participation. For a sensitive report,
request a private contact method through the repository owner's GitHub profile.
Reports will be shared only as needed to investigate and resolve the matter.

This policy applies to every official project space.
